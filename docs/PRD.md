# 我的秘密宇宙：MVP 产品需求文档

## 1. 产品概述

「我的秘密宇宙」帮助用户记录、探索个人微小好奇，并通过思维连接发现共鸣。用户是自己动态 3D 宇宙的创造者，也可以漫游他人的宇宙。

核心理念：**不要让用户成为内容生产者，让用户成为宇宙创造者。**

## 2. MVP 目标与边界

### 目标

- 让用户快速记录好奇点，并在个人宇宙中看到它。
- 围绕好奇点持续记录探索过程。
- 让用户确认、保留独立或暂缓判断星球之间的连接。
- 通过宇宙的动态变化体现长期探索价值，而非签到或每日任务。

### MVP 包含

- 个人宇宙首页
- 创建好奇点
- 星球详情
- 添加好奇轨迹
- 基础连接交互
- 他人宇宙漫游、相似好奇发现（可先使用示例数据）

### 暂不包含

点赞、评论、私信、关注、排行榜、商业功能、复杂 AI 分析、真实多人社交、复杂星球物理模拟，以及非首版必需的真实天文学功能。

## 3. 核心概念与视觉语义

- **宇宙**：一个用户的动态 3D 好奇空间。
- **恒星**：用户创建的第一个独立好奇点。
- **小行星**：之后创建的独立好奇点。
- **好奇轨迹**：对同一个好奇点的深入探索时间线；每一步不创建新星球。
- **连接**：两个好奇点之间的思维关系。天体和连线应有明确含义，宇宙会随探索动态变化。

## 4. 关键用户流程

### 4.1 创建好奇点

1. 用户在个人宇宙首页点击创建入口。
2. 展示文案「此刻，你在好奇什么？」。
3. 用户填写好奇内容（必填）；填写灵感来源（选填，提示「这个好奇从哪儿冒出来的？」）。
4. 不要求分类、标签或长篇描述。
5. 保存后，第一个独立好奇点生成恒星，之后的独立好奇点生成小行星，并出现在宇宙中。

### 4.2 探索星球

1. 用户点击天体进入星球详情。
2. 查看好奇内容、灵感来源和按时间排序的好奇轨迹。
3. 用户添加新的轨迹记录，记录探索所得或新的问题；不生成新星球。
4. 关闭详情后，仅提供两个推荐方向：「看看类似的好奇有谁在好奇」和「看看别人在好奇什么」。

### 4.3 处理潜在连接

1. AI 可以提出两个好奇点可能存在联系的假设。
2. AI 不得擅自创建连接；用户可选择「确认连接」「保持独立」或「暂不判断」。
3. 用户确认的连接与系统提出的潜在连接必须有不同状态和视觉表达。
4. 用户明确拒绝的同一条连接不应被反复推荐。

## 5. 功能需求

### 5.1 个人宇宙首页

- 展示用户的 3D 宇宙、恒星、小行星及连接状态。
- 支持拖拽旋转、缩放、点击天体等基础操作。
- 提供创建好奇点入口；空状态提供首次创建引导。

### 5.2 星球详情与轨迹

- 展示好奇点原始内容、灵感来源和创建时间。
- 展示按时间排序的好奇轨迹。
- 支持新增轨迹，并立即更新详情和宇宙呈现。

### 5.3 连接交互

- 展示待判断的潜在连接及假设说明。
- 支持确认、保持独立、暂不判断，并持久化状态。
- 对明确拒绝的连接不再重复推荐。

### 5.4 漫游与发现（示例数据）

- 提供进入他人宇宙的入口。
- 使用示例数据展示类似好奇和他人好奇。
- MVP 不要求真实多人数据、社交关系或实时同步。

## 6. 数据与状态建议

- `Curiosity`：好奇内容、灵感来源、类型（恒星/小行星）、创建时间。
- `TrailEntry`：所属好奇点、文字内容、创建时间。
- `Connection`：两个好奇点、来源（用户确认/系统假设）、状态（待判断/已确认/保持独立/暂不判断/已拒绝）。
- 首版使用单用户本地持久化，数据结构预留后续接入服务端的空间。

## 7. 非功能要求与验收标准

- 零基础开发者能够启动、理解和修改原型。
- 首屏可运行，核心操作无需登录即可演示。
- 创建好奇点、查看详情、添加轨迹、处理连接均有明确反馈。
- 3D 视觉服务于信息理解，低性能设备也能完成核心操作。
- 验收路径：创建首个恒星 → 创建第二个小行星 → 添加轨迹 → 查看潜在连接 → 确认或保持独立 → 关闭并进入发现方向。

## 8. 下一阶段技术选型建议

- **框架**：Vite + React + TypeScript，启动快、结构清晰，适合持续迭代。
- **3D**：Three.js，优先使用 `@react-three/fiber` 与 `@react-three/drei` 简化 React 中的场景、相机和交互。
- **样式**：先用普通 CSS 或 CSS Modules，减少依赖并方便调整视觉表现。
- **状态与持久化**：先用 React 状态加 `localStorage`；数据模型稳定后再评估状态库和后端。
- **测试**：先覆盖核心数据操作和连接状态转换，再补充关键交互测试。
- **实施顺序**：先做可点击的 3D 宇宙与本地数据闭环，再加入示例漫游，最后接入 AI 连接假设。
